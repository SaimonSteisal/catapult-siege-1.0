# GDD — Catapult Siege: Осадный расчёт (v1.0)

Реализованное игровое дизайн-документ. Числа синхронизированы с `src/config.js`
(единственный источник истины; расхождения трактуются в пользу конфига).

## 1. Столпы дизайна
1. **Цена промаха.** Каждый выстрел тратит боеприпас, снабжение и ресурс узла орудия.
   Точность = валюта. Миссия оценивается КПД = добыто/израсходовано.
2. **Орудие — живой механизм.** 6 узлов с износом, ремонтом в бою и катастрофой
   при разрушении рамы. Игрок обслуживает машину, а не просто «жмёт кнопку».
3. **Осада умом.** Ветер, баллистика, разрушаемость с каскадными обрушениями,
   контрбатарейный огонь и мирные постройки со штрафами формируют тактику.

## 2. Короткий цикл (5–20 с)
наводка (drag на AIM PAD) → заряд/взвод (анимация COCK) → выстрел → полёт (камера-слежение,
slow-mo на попадании) → разрушение/лут → корректировка (призрачная трасса, подсказки).

## 3. Управление (тач, portrait-first)
| Жест | Действие |
|---|---|
| drag по AIM PAD | наводка: вертикаль = возвышение 2–85°, горизонталь = азимут ±32°, дистанция перетаскивания = мощность 30–100% |
| отпустить над AIM PAD | выстрел |
| увести в красную зону слева-снизу и отпустить | отмена без расхода |
| 1 палец по вьюпорту | орбита камеры |
| pinch | зум 9–92 м |
| 2 пальца drag | панорама ±42 м |
| double-tap | сброс камеры |
| tap по цели | карточка цели + маркер + фокус |
| long-press по вьюпорту | панель узлов (осмотр/ремонт) |
| hold «Ремонт» 0.7 с | ремонт худшего узла за снабжение+ресурсы |
| кнопка ОГОНЬ | выстрел с текущими параметрами |
| «Точный» | слайдеры азимут/возвышение/мощность с шагом 0.5° (доступность) |
Time-freeze: во время наводки мир замирает (D6), полёт и враг — реал-тайм.

## 4. Орудие (требушет)
Узлы: Рама 220 HP, Противовес 180, Коромысло 200, Ось 140, Стропа 120, Ложе 160.
Влияние повреждений: см. `CFG.trebuchet.effects` (мощность/рассеивание).
Износ за выстрел: 2.6% + 3.4%·мощность (×модификаторы). Стропа при 0 HP: шанс обрыва 55%.
Рама при 0 HP: катастрофа = провал миссии.
Анимация: 6 фаз LOAD→COCK→AIM→RELEASE→SWING→RECOVER, физичная кинематика плеча,
взвод лебёдкой, приседание рамы от отдачи, процедурный расчёт из 4 ролей с анимациями.

## 5. Боеприпасы (8)
Камень, Гранитное, Зажигательное (DoT+поджог дерева), Картечь (площадь),
Разрывное (фугас 0.4 с), Якорь-болт (пробитие), Улей (отвлечение ПВО), Точёное (σ×0.35).
Стоимость и урон — `CFG.ammo`. Открытие: ранги + узлы ветки «Боеприпасы».

## 6. Цели и разрушаемость
Блоки-префабы (камень/кирпич/дерево/металл/верёвка/ткань/смола/золото), HP и модификаторы
урона — `CFG.blocks.materials`. Support-graph: обрушение каскадом до 14 уровней.
Обломки — пул до 140, физика + затухание 4 с. Цепные реакции складов.
Типы целей: стена, башня, ворота, склад, орудие врага, казарма, штандарт, командир,
мельница/часовня (штраф 40/80 монет). Баунти — `CFG.targetTypes`.

## 7. Баллистика и ветер
Полунеявный Эйлер, шаг 1/120, гравитация 9.81, лобовое сопротивление k·v² (по массе ядра),
ветер = база миссии + порывы (шум+синус), связь с высотой. v0 = 34·(0.55+0.78·P)·√eff,
потолок 54 м/с. Рассеивание: конус Гаусса σ = f(износ, ветер, качество ядра, навык, усталость).
Предиктивная дуга 26 точек (13 видимых) + эллипс рассеивания + призрачная трасса прошлого выстрела.

## 8. Расчёт (4 роли)
Наводчик (Замер: идеальная дуга 8 с; −8% σ/ур.), Заряжающий (Двойной заряд +25% мощности,
+износ; −20% взвод), Инженер (Аварийный ремонт 35% худшего узла; −15% износа),
Командир (Боевой клич ×2 урон, −10% лута; +10% монет). Усталость 6–14/выстрел,
при 100 — скилл недоступен, σ×1.6. Отдых/паёк/обучение за монеты. Слоты 2→4 (техдерево).

## 9. Экономика
Ресурсы: камень, дерево, металл, верёвка, смола, монеты, чертежи, снабжение (бюджет вылазки).
Выстрел = стоимость ядра (из кармана) + 7.65–9 снабжения. Ремонт в бою ×1.5 цены + 14 снабжения.
Лагерь: 5 построек idle-добычи с уровнями/капами/оффлайн-сбором (8 ч, 60%), рынок купля/продажа.
Отчёт снабженца: израсходовано/добыто/КПД/ранг S–D (пороги 2.5/1.8/1.2/0.7),
множитель награды ×2.0/1.5/1.2/1.0/0.6. Штрафы за мирных. Идеальный выстрел (≤1.6 м от центра): +XP/монеты.

## 10. Прогрессия
Ранги: Рекрут→…→Гранд-канонир (6 рангов × 10 уровней). Техдерево «Чертёжная»: 5 ветвей,
41 уровень + 7 именованных узлов = 48; 12 синергий (замки с подсказками).
Трофеи-коллекция (96+) за типы разрушенных целей. Косметика — заглушка roadmap 1.1.

## 11. Миссии
Кампания 5 глав × 8 контрактов (40) + боссы-цитадели (главы 3–5, финал).
Виды: DEMOLISH / SNIPER (лимит снарядов) / SIEGE (брешь) / SABOTAGE (орудия, беречь мирных) /
DEFEND (таймер+волны) / ECONOMY (бюджет 62%, КПД≥1.35) / BOSS (3 фазы).
Модификаторы: штиль, шквал, дождь, туман, ночь, хрупкая рама, дефицит, элитный гарнизон,
щедрый заказчик (множители награды/риска). Сид миссии детерминирован (hash(id)).
Ежедневно: Контракт дня (фикс-сид), Испытание (3 снаряда), Полигон (бесконечно, без наград).
12 параметрических схем крепостей × 4 биома (луга/река/горы/зима/берег).

## 12. Враг
Гарнизон: инстанс-солдаты с ИИ patrol/cover/flee/repair (чинят блоки!). Контрбатарейный огонь:
задержка 4.5–9 с, урон 8–22 по случайному узлу, точность растёт с живыми орудиями и тревогой;
маркер «ОГОНЬ НА ВАС» с задержкой детонации 1.5 с. Волны в DEFEND.

## 13. Обучение и подсказки
6 шагов интерактивного туториала (жест→выстрел→ветер→ремонт→экономика→скиллы), награда 120 монет.
Контекстные подсказки при промахе («Недолёт 4.2 м — добавьте мощности»), отключаемые (aimAssist).
Автонаводка первого выстрела: численный решатель по фактическому интегратору (учитывает
сопротивление и ветер) — игрок сразу видит дугу на цели и учится корректировать.

## 14. Доступность
Масштаб UI 0.85–1.3, режимы дальтонизма (SVG-фильтры), reduce-motion, субтитры звуков (roadmap),
левша-режим (roadmap-флаг), точное прицеливание слайдерами, отключение slow-mo/тряски,
кнопки ≥48 dp, контраст ≥4.5:1.

## 15. Баланс-цели (проверено balance-report, патч 1.0.1)
Снабжение вылазки 150 + 10/главу, выстрел = 9 снабжения + стоимость ядра (оплачена в брифинге).
Камень бьёт каменный блок за один удар кинетикой; оверкилл пробивает соседей (radius 1.7, ×0.28).
Цель = руины при 28% HP. Полигон проходится за ~9 выстрелов; глава 1 новичком ≥ 85%.
Проходимость 1-й попытки: гл.1 ≥90% … гл.5 ≈35%; средний КПД активного игрока 1.6–2.2;
доля рангов S ≤12% без техдерева, ≤30% с полной веткой точности.
