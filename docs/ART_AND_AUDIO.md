# ART & AUDIO BIБLE — Catapult Siege

## Арт-направление
**Стиль:** стилизованный low-poly «тёплое средневековье»: крупные фаски, читаемые силуэты,
никакого фотореализма. Освещение — закатное солнце `#FFD9A0` + hemi `#8FB4D9/#6A5C42`.
**Шейдинг:** MeshLambert + flatShading (дешёвый «toon» без кастомных шейдеров), vertex-color рельеф.
**Палитра сцены:** трава `#7A8A4F` (зима `#DFE8EE`), камень `#9C968A`, дерево `#7A5533`,
железо `#6E7278`, враг — холодные сине-серые `#3D5A80/#4A5F7A`, игрок — охристые `#C9873A`.
**UI-палитра:** пергамент `#E8DCC0`, тёмное дерево `#3A2A1C`, угроза `#B3372C`, золото `#D9A62E`,
успех `#5C8A3A`. Контраст текста ≥4.5:1, цифры tabular-nums.

## Процедурные текстуры (0 ассетов)
canvas 256²/128²: дерево (волокна+сучки), камень (крап+швы кладки+сколы), металл (царапины+ржавчина),
верёвка (диагональная свивка), трещины (рекурсивные ветви, декаль), soft-particle, spark-streak.
Mipmaps + anisotropy 4, RepeatWrapping.

## Геометрия
- Требушет: брус-коромысло с железными обоймами, А-рамы, ось, противовес-ящик на стропах,
  стропа с кожаной сумкой, лебёдка, визир наводчика, ложе с ядрами, флаг игрока.
- Расчёт: капсула+сфера+конус-шлем, руки/ноги на pivots; инструмент роли (визир/шомпол/молот/флаг).
- Крепости: блоки 1.25 м; башни 3×3 с деревянной галереей и конической крышей; ворота с
  металлическими петлями (крит-точка); мельница с парусами; часовня; вражеские требушеты.
- Окружение: heightmap 64² с биом-покраской по высоте/уклону, instanced трава/камни,
  2–3-ярусные ели (зимой со снегом), silhouette-горы 2 слоя, gradient-sky dome, лагерные
 .props: палатки, ящики, костёр с point-light.

## FX-словарь
дым (billboard-пул 44), искры (additive 64), вспышки (12), пылевые кольца, декали воронок,
огненные столбы + point-light, брызги воды, трасс снаряда (16 сегм.), призрачная трасса,
предиктивная дуга (пунктир+точки+эллипс рассеивания), маркер цели (torus-пульс),
float-номера урона (DOM), screen-shake ≤6 px, hit-stop 70 мс, slow-mo 0.22–0.28× на 0.55–0.65 с.

## Звук (процедурный WebAudio)
| Событие | Рецепт |
|---|---|
| Выстрел | sub-sine 130→38 Гц + noise-крак lowpass 1.5 кГц + bandpass-щелчок строны 2.6 кГц + wood-groan |
| Свист ядра | loop-noise → bandpass Q9, частота следует скорости (Doppler-подобно), пан по азимуту |
| Удар камень/дерево/металл | транзиент + резонансный bandpass 400–900 / серия тресков / металлич. обертоны 2.2+3.1 кГц |
| Разрушение | гранулярный шум 8–16 burst'ов + sub 70 Гц |
| Взрыв | sine 90→28 Гц + noise lowpass 900→70 Гц + highpass-щелчок; duck музыки −6 дБ |
| Лебёдка | saw-скрип 190→260 Гц + 7 ratchet-кликов bandpass 2.4 кГц |
| UI | sine 880 Гц 40 мс (тап), 420→300 (назад), мажорное арпеджио (успех), нисходящий минор (провал) |
| Ветер | loop brown-noise → lowpass, громкость/частота от силы ветра и порывов |
| Музыка | drone: 3×2 detuned saw → lowpass с LFO 0.045 Гц; frame-drum пульс 74–108 BPM по интенсивности боя; мелодич. пинг в покое |
Микс: master→compressor(−14 dB)→limiter; шины SFX/MUSIC/UI с громкостью в настройках; пул 24 голоса.

## Типографика и иконографика
Системный гротеск (Roboto/Noto Sans/PT Sans), веса 400/700/900; заголовки uppercase с трекингом .06em.
Иконки — emoji-глифы платформы (0 ассетов) + inline-SVG (роза ветров). Ранги S–D — круглый бейдж с pop-анимацией.
