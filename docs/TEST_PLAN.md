# TEST PLAN — Catapult Siege 1.0

## Уровни тестирования
1. **Headless-юниты** (`npm test` → `tools/headless-test.mjs`, Node, без DOM/WebGL):
   детерминизм RNG и миссий, математика sphere-OBB, согласованность предикции и интегратора,
   монотонность цен техдерева, границы computeMods, арифметика лагеря/рынка, пороги рангов.
2. **Баланс-симуляция** (`npm run balance` → `tools/balance-report.mjs`): 2000 синтетических миссий
   на главу: распределение КПД/рангов, проходимость, цена выстрела vs лут, проверка «нет вырожденного фарма».
3. **E2E в браузере** (`tools/test-browser.mjs`, headless Chrome + SwiftShader WebGL2):
   бут без ошибок → все экраны → брифинг → бой → выстрелы через игровой солвер → разрушения/лут →
   итоги; сбор скриншотов, console/pageerror/requestfailed-фильтр, метрики draw calls/tris/heap.
4. **Ручной чек-лист на устройстве** (§13 PROMPT.md) перед AAB.

## Ручной чек-лист устройства (excerpt, полный — §13 PROMPT.md)
- Мокрый палец/рукавичный тест dead-zone; мультитач камера+наводка; ротация; notch-зоны;
- сворачивание/звонок → автопауза, возврат без потери состояния; 30 мин сессия: heap-профиль без роста;
- авиа-режим: полная играбельность; low-end: 30 FPS стабильно после auto-quality.
